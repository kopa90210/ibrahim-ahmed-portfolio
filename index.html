Senior engineering is defined by trade-offs. Inspect how I refactored naive implementations into resilient, high-throughput production architectures.

ADR-01 • ACCEPTED & DEPLOYED p95 Latency: -98%

Decoupling LLM Generation from Request-Time UI Thread

Calling Groq/LLM APIs synchronously inside a user's HTTP request created 3.5s+ page freezes, exposed the UI to rate-limit 429 errors, and occasionally recommended out-of-stock item IDs.

Trade-Offs Evaluated

Sacrificed: Instantaneous ad-hoc prompt tweaking per page refresh.
Gained: 0ms LLM blocking on page load, 100% catalog integrity via pre-persistence item-pool validation, and automatic fallback to deterministic styling when model confidence drops below 0.85.
