## Quick Deployment to GitHub & Vercel

```bash
git init
git add .
git commit -m "feat: launch senior full-stack .NET & AI impact portfolio"
git branch -M main
git remote add origin https://github.com/kopa90210/ibrahim-ahmed-portfolio.git
git push -u origin main
```

Then import `kopa90210/ibrahim-ahmed-portfolio` in [Vercel](https://vercel.com/new) with **Framework Preset: Other** and click **Deploy**.
